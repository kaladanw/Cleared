Load Cleared in Chrome

  1. Get the extension folder

    Use the extension folder shared with your invite.

  2. Open Chrome extensions

    chrome://extensions

  3. Turn on Developer mode

    Use the switch in the top-right corner.

  4. Choose Load unpacked

    Select the extension folder.

Then open a Depop listing. Cleared appears on the page; sign in once more inside the extension.
